## Selected projects

These public projects provide examples of my approach to frontend and full-stack development.

### [Management Dashboard](https://github.com/mishs/management-dashboard)
A task-management frontend built with React, TypeScript, Redux Toolkit, and Material UI. It explores drag-and-drop workflows, task ordering, and API state using a mocked backend, with Storybook and Vitest tooling.

### [eCommerce Full-Stack](https://github.com/mishs/eCommerce-fullstack)
An e-commerce project organised as a TypeScript monorepo, with separate React frontend, Express backend, and shared-type workspaces. Its structure brings client and server development into one codebase while keeping their responsibilities separate.

### [HubSpot Integration Demo](https://github.com/mishs/fullstack-hubspot_CMS)
A full-stack assessment project for viewing, creating, and deleting contacts through the HubSpot API. It separates the React interface from the server-side API integration and uses fictional contact data.
